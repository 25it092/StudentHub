Frequently Asked Questions



What is StudentHub?

StudentHub is a student portal for managing academic information, events, notices and student activities.

How can I register on StudentHub?

Open the Register page, enter your details and submit the registration form.

How can I log in?

Open the Login page and enter your registered email and password.

Can I update my profile?

Yes, students can update their profile information from the Profile page.

Where can I find upcoming events?

You can view upcoming college events on the Events page.

How can I search for an event?

Use the search box on the events data page to find an event by its title.

Can I filter events?

Yes, events can be filtered according to their category.

What information is required during registration?

You need to provide your name, email, mobile number, password, course, year, gender and accept the terms.

What should my password contain?

Your password should contain at least 8 characters, an uppercase letter, a lowercase letter, a number and a special character.

Can I use StudentHub on a mobile device?

Yes, StudentHub is designed to work on mobile, tablet and desktop screens.

How can I find student information?

Student information can be displayed from the students JSON dataset on the student data page.

What is the purpose of the FAQ section?

The FAQ section provides answers to commonly asked questions about StudentHub.

Can events be sorted?

Yes, the event records can be sorted using JavaScript array sorting.

What happens if JSON data cannot be loaded?

A user-friendly error message can be displayed when the JSON data cannot be loaded.

What is Fetch API used for?

Fetch API is used to request and retrieve JSON data from an external file and use it in the webpage.
